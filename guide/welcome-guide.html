Thanks for installing multiAccounts

How to use multiAccounts

Pin multiAccounts after install extension
Click on multiAccounts icon or (Alt+H ) to open multiAccounts popup Window

Extension pinned status: Not pinned
Global Keyboard shortcuts
Format Action Keyboard Shortcut Action
Open popup window Alt+Shift+M

multiAccounts doesn't ask permission: "Read and change all your data on all websites".
So that you need to click again on Add Account button to add account

How to add account on any websites

Click on Add account to add account

How to open account on new tab

Click on Open link icon on top right corner of account card. Website with this account will open in new tab

Organize account - group account

Click on Drop down icon next to Group text.
Select existing tabGroups or create new tabGroups.

Export files

Click on File Export icon on top right corner to export all accounts in JSON format
then you can import exported JSON file from any chromium browser on any devices.

Import Account

Click on account plus on top right corner.
Pick json file which contain account info
Supported format: JSON (exported from this extension)
